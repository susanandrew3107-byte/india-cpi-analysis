# India Consumer Price Index (CPI) Analysis

## Project Overview
Analyzed India's Consumer Price Index (CPI) data from 2013 to 2024 using Microsoft Excel to understand inflation trends and compare price changes across Rural, Urban, and Rural + Urban sectors.

## Tools Used
- Microsoft Excel
- Data Cleaning
- PivotTables
- Charts and Data Visualization
- Year-on-Year Trend Analysis

## Key Objectives
- Analyze CPI changes over time.
- Compare inflation trends across sectors.
- Identify categories showing notable price changes.
- Present findings through charts and data-driven insights.
